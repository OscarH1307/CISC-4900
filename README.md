### So lets get started:  
      1) Install the required program from the installation.md  
      2) Download the raw file:  
          index.html // Frontend of the website  
          style.css // Design of the wesbite  
          script.js // interactive and animation of the website  
          server.js // connection to local host and connecting to Clover server  
          pictures // required images  
      3) create a empty folder and add all the files into that  
      4) Open the folder using Visual Studio Code and the Open Bash terminal  
      5) In Bash here is what you want to do:  
              - npm install <- this will install node into the file  
              - npm install express axios dotenv <- this will install required package such as "express", "axios" and "dotenv"  
              -node server.js <- this will boot up local host for you  
      6) After you receive "Server running at http://localhost:{whatever host number} you can copy that link and paste it to the url  
      7) Now you should be able to interact with the website.
